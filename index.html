Module 1

Introduction à Node.js

1.1 Qu'est-ce que Node.js ?

Node.js est un environnement d'exécution JavaScript côté serveur open source et multiplateforme. Il vous permet d'exécuter du code JavaScript en dehors d'un navigateur web. Il est construit sur le moteur JavaScript ultra-rapide V8 de Google Chrome.

1.2 Pourquoi utiliser Node.js ?

  • Full-stack JavaScript : Si vous connaissez déjà JavaScript pour le frontend (React, Vue, etc.), vous pouvez l'utiliser aussi pour le backend.
  • Performance exceptionnelle : Grâce à son modèle non bloquant (asynchrone) et orienté événements, Node.js est parfait pour gérer des milliers de connexions simultanées (chats, streaming, API rapides).
  • Écosystème riche : Le registre NPM (Node Package Manager) est la plus grande bibliothèque de code open-source au monde.

1.3 Architecture de Node.js (Event Loop)

La magie de Node.js réside dans son Event Loop (boucle d'événements). Node.js est monothreadé (un seul fil d'exécution principal), mais il délègue les tâches lourdes (lire un fichier, interroger une base de données, requêtes réseau) au système d'exploitation.

L'Event Loop surveille la fin de ces tâches en arrière-plan et exécute les fonctions de rappel (callbacks) correspondantes sans jamais bloquer le programme principal.

Module 2

Configuration de l'Environnement

2.1 Installation

Pour commencer à coder, vous devez installer Node.js sur votre machine :

  1. Visitez le site officiel : nodejs.org
  2. Téléchargez et installez la version LTS (Long Term Support). C'est la plus stable.
  3. Ouvrez votre terminal (Invite de commandes, PowerShell ou Terminal macOS/Linux).
  4. Vérifiez l'installation en tapant ces deux commandes :
node -v
npm -v

Si des numéros de version s'affichent, félicitations, vous êtes prêt !

2.2 Votre premier programme Node.js ("Hello World")

Créez un dossier pour votre projet, ouvrez-le dans votre éditeur de code (comme VS Code), et créez un fichier nommé app.js.

// app.js
console.log("Bonjour, Monde ! Ceci est mon premier programme Node.js.");

const nom = "Alice";
console.log(`Salut, ${nom} !`);

Pour l'exécuter, ouvrez votre terminal dans le même dossier et tapez :

node app.js
Module 3

Les Fondamentaux de Node.js

3.1 Objets Globaux

Contrairement au navigateur où window est l'objet global, dans Node.js, nous utilisons d'autres objets globaux intégrés :

  • process : Informations sur le processus actuel (ex: process.env pour les variables d'environnement).
  • __dirname : Le chemin absolu du dossier où se trouve le fichier actuel.
  • __filename : Le chemin absolu du fichier actuel.

3.2 Le Système de Modules (CommonJS)

Pour organiser votre code, Node.js utilise module.exports et require.

// 1. Créez un fichier math.js
const add = (a, b) => a + b;
const subtract = (a, b) => a - b;

module.exports = { add, subtract };

// 2. Dans votre fichier app.js
const math = require('./math');
console.log(math.add(5, 3)); // Affiche 8

3.3 Le Module fs (File System)

Permet de lire et écrire des fichiers sur votre ordinateur. Il est recommandé d'utiliser la version asynchrone avec les promesses pour ne pas bloquer l'Event Loop.

const fs = require('fs').promises;

async function gererFichier() {
    try {
        // Écrire un fichier
        await fs.writeFile('test.txt', 'Bonjour Node.js !');
        console.log('Fichier créé.');

        // Lire le fichier
        const data = await fs.readFile('test.txt', 'utf8');
        console.log('Contenu du fichier :', data);
    } catch (err) {
        console.error("Erreur :", err);
    }
}

gererFichier();

3.4 Le Module http : Créer un serveur web basique

Node.js intègre un module pour créer des serveurs web sans aucune bibliothèque externe.

const http = require('http');

const server = http.createServer((req, res) => {
    // req = Requête du client (navigateur)
    // res = Réponse que le serveur va envoyer
    
    res.statusCode = 200;
    res.setHeader('Content-Type', 'text/plain; charset=utf-8');
    res.end('Bonjour depuis mon premier serveur Node.js !');
});

server.listen(3000, () => {
    console.log('Serveur en écoute sur le port 3000 (http://localhost:3000)');
});
Module 4

NPM (Node Package Manager)

NPM est le gestionnaire de paquets par défaut de Node.js. C'est grâce à lui que vous pouvez installer des bibliothèques externes (comme Express, React, Mongoose) créées par la communauté.

4.1 Initialiser un projet

Avant d'installer des paquets, vous devez initialiser votre projet. Dans le terminal, tapez :

npm init -y

Cela crée un fichier package.json. Ce fichier est la "carte d'identité" de votre projet. Il liste le nom du projet, sa version, et surtout, toutes les dépendances (bibliothèques) dont il a besoin pour fonctionner.

4.2 Installer des packages

Pour installer un paquet, on utilise npm install (ou npm i) :

# Installe Express.js (dépendance de production)
npm install express      

# Installe Nodemon (dépendance de développement uniquement)
npm install nodemon -D

Note : nodemon est un outil magique qui relance automatiquement votre serveur Node.js à chaque fois que vous sauvegardez un fichier. Plus besoin d'arrêter et de relancer le serveur manuellement !

4.3 Scripts NPM

Dans votre package.json, vous pouvez définir des raccourcis de commandes dans la section "scripts" :

"scripts": {
  "start": "node app.js",
  "dev": "nodemon app.js"
}

Maintenant, pour lancer votre serveur en mode développement, il suffit de taper dans le terminal :

npm run dev
Module 5

Construire des Applications avec Express.js

Bien que le module http natif soit puissant, il devient vite complexe pour de grosses applications. Express.js est le framework web le plus populaire pour Node.js. Il simplifie énormément la création de serveurs, la gestion des routes (URL) et la manipulation des requêtes/réponses.

5.1 Premier serveur Express

Assurez-vous d'avoir installé Express (npm install express), puis créez votre serveur :

const express = require('express');
const app = express();
const PORT = 3000;

// Middleware pour autoriser la lecture de JSON envoyé par le client
app.use(express.json());

// Route GET basique (quand l'utilisateur visite l'URL racine '/')
app.get('/', (req, res) => {
    res.send('Bienvenue sur mon API Express ! 🚀');
});

app.listen(PORT, () => {
    console.log(`Serveur Express démarré sur http://localhost:${PORT}`);
});

5.2 Routage et Paramètres

Express rend la récupération de données depuis l'URL ou le corps de la requête très intuitive.

// 1. Récupérer un paramètre d'URL (ex: visite de /users/42)
app.get('/users/:id', (req, res) => {
    const userId = req.params.id; // Récupère le "42"
    res.json({ 
        message: `Détails de l'utilisateur ${userId}`,
        id: userId
    });
});

// 2. Récupérer des données d'une requête POST (ex: formulaire d'inscription)
app.post('/users', (req, res) => {
    // req.body contient les données envoyées au format JSON
    const userData = req.body; 
    
    // On renvoie un code HTTP 201 (Created)
    res.status(201).json({ 
        message: 'Utilisateur créé avec succès !', 
        data: userData 
    });
});
Module 6

Bases de Données (MongoDB & Mongoose)

6.1 Introduction à MongoDB

Une application backend a besoin de sauvegarder des données de manière persistante. MongoDB est une base de données NoSQL extrêmement populaire dans l'écosystème Node.js. Contrairement aux bases de données SQL (tableaux), MongoDB stocke les données sous forme de documents JSON flexibles.

6.2 Mongoose : L'outil indispensable

Pour faire le pont entre notre code Node.js et MongoDB, nous utilisons Mongoose. Il nous permet de définir des structures de données strictes (Schémas) et d'interagir facilement avec la base.

Installation : npm install mongoose

6.3 Connexion et Création de Modèle

const mongoose = require('mongoose');

// 1. Connexion à la base de données MongoDB (locale ou Atlas dans le cloud)
mongoose.connect('mongodb://localhost:27017/mabase')
    .then(() => console.log('✅ Connecté à MongoDB'))
    .catch(err => console.error('❌ Erreur de connexion', err));

// 2. Création d'un Schéma (la structure de notre donnée)
const tacheSchema = new mongoose.Schema({
    titre: { type: String, required: true },
    description: { type: String },
    terminee: { type: Boolean, default: false },
    dateCreation: { type: Date, default: Date.now }
});

// 3. Création du Modèle (l'objet qui nous permettra d'interagir avec la collection)
const Tache = mongoose.model('Tache', tacheSchema);

// On peut maintenant utiliser Tache.find(), Tache.create(), etc.
module.exports = Tache;
Module 7

Projet Complet : API REST de Gestion de Tâches

Mélangeons tout ce que nous avons appris (Express) pour créer une véritable API CRUD (Create, Read, Update, Delete). Pour cet exemple, afin qu'il fonctionne immédiatement sans installation de base de données externe, nous utiliserons un tableau en mémoire pour simuler la base de données.

const express = require('express');
const app = express();
app.use(express.json()); // Indispensable pour lire le JSON

// Simulation de notre Base de données
let taches = [
    { id: 1, titre: "Apprendre Node.js", terminee: false },
    { id: 2, titre: "Créer une API REST", terminee: true }
];

// ==========================================
// R - READ : Récupérer toutes les tâches
// ==========================================
app.get('/taches', (req, res) => {
    res.json(taches);
});

// ==========================================
// C - CREATE : Ajouter une nouvelle tâche
// ==========================================
app.post('/taches', (req, res) => {
    if (!req.body.titre) {
        return res.status(400).json({ erreur: "Le titre est obligatoire." });
    }
    
    const nouvelleTache = {
        id: taches.length > 0 ? taches[taches.length - 1].id + 1 : 1,
        titre: req.body.titre,
        terminee: false
    };
    taches.push(nouvelleTache);
    res.status(201).json(nouvelleTache); // 201 = Créé avec succès
});

// ==========================================
// U - UPDATE : Modifier une tâche (la marquer terminée)
// ==========================================
app.put('/taches/:id', (req, res) => {
    const id = parseInt(req.params.id);
    const tache = taches.find(t => t.id === id);
    
    if (!tache) {
        return res.status(404).json({ erreur: 'Tâche non trouvée' });
    }
    
    // Mise à jour
    tache.terminee = req.body.terminee !== undefined ? req.body.terminee : tache.terminee;
    tache.titre = req.body.titre || tache.titre;
    
    res.json(tache);
});

// ==========================================
// D - DELETE : Supprimer une tâche
// ==========================================
app.delete('/taches/:id', (req, res) => {
    const id = parseInt(req.params.id);
    const index = taches.findIndex(t => t.id === id);
    
    if (index === -1) {
        return res.status(404).json({ erreur: 'Tâche non trouvée' });
    }
    
    taches.splice(index, 1); // Supprime l'élément du tableau
    res.status(204).send(); // 204 = No Content (Suppression réussie)
});

// Lancement du serveur
app.listen(3000, () => {
    console.log('✅ API de tâches démarrée sur http://localhost:3000');
});
Modules 8 & 9

Concepts Avancés et Prochaines Étapes

Félicitations ! Vous avez maintenant les bases de Node.js et d'Express. Pour créer des applications professionnelles prêtes pour la production, voici les concepts cruciaux vers lesquels vous devez vous diriger :

1. Sécuriser les secrets (Variables d'environnement)

Ne stockez jamais vos mots de passe de base de données ou vos clés secrètes d'API en texte clair dans votre code. Utilisez le paquet dotenv pour charger ces informations depuis un fichier caché .env non publié sur GitHub.

2. Hachage des mots de passe

Si vous créez un système d'utilisateurs, utilisez la bibliothèque bcrypt pour "hacher" (crypter de façon irréversible) les mots de passe avant de les sauvegarder en base de données.

3. Authentification (JWT)

Apprenez à utiliser les JSON Web Tokens (JWT). Lorsqu'un utilisateur se connecte, vous lui donnez un jeton (token). Il devra renvoyer ce jeton lors de ses prochaines requêtes pour prouver son identité sans avoir à renvoyer son mot de passe à chaque fois.

4. Temps réel avec Socket.IO

Pour créer un chat en direct, un tableau de bord qui s'actualise seul, ou un jeu multijoueur, les requêtes HTTP classiques ne suffisent pas. Apprenez à utiliser Socket.IO, qui permet une communication bidirectionnelle en temps réel (WebSockets) entre le serveur et le client.
