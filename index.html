Module 1 - Chapitre 1 : Les Bases des Réseaux

Pour comprendre comment attaquer un réseau, il faut d'abord comprendre comment il fonctionne. Les réseaux sont le système nerveux d'Internet et de toute infrastructure numérique.

1. Le Modèle OSI (Open Systems Interconnection)

Le modèle OSI est un concept théorique qui divise les fonctions de communication réseau en sept couches distinctes. Chaque couche a une fonction spécifique et interagit avec les couches adjacente. Bien qu'il soit plus un modèle de référence, il aide à visualiser le flux de données.

  • Couche 7 : Application (Ex: HTTP, FTP, SMTP, DNS) - C'est l'interface avec les applications utilisateur.
  • Couche 6 : Présentation (Ex: Cryptage/Déchiffrement, Compression) - Assure que les données sont dans un format utilisable par la couche application.
  • Couche 5 : Session (Ex: NetBIOS, RPC) - Établit, gère et termine les sessions entre les applications.
  • Couche 4 : Transport (Ex: TCP, UDP) - Gère la segmentation des données, le contrôle de flux et la détection d'erreurs.
  • Couche 3 : Réseau (Ex: IP, ICMP) - Gère l'adressage logique (IP) et le routage des paquets à travers le réseau.
  • Couche 2 : Liaison de Données (Ex: Ethernet, PPP, Wi-Fi) - Gère l'adressage physique (MAC), la détection d'erreurs au niveau de la trame.
  • Couche 1 : Physique (Ex: Câbles, Fibres optiques, Ondes radio) - Gère la transmission physique des bits.

2. Le Modèle TCP/IP (Transmission Control Protocol/Internet Protocol)

Le modèle TCP/IP est plus pratique et est celui réellement implémenté sur Internet. Il est plus condensé, fusionnant certaines couches de l'OSI.

  • Couche Application (OSI 5, 6, 7) : Regroupe les fonctions des couches Application, Présentation et Session de l'OSI. C'est là que les protocoles comme HTTP, FTP, DNS opèrent.
  • Couche Transport (OSI 4) : Identique à l'OSI, avec TCP (fiable, orienté connexion) et UDP (rapide, non fiable, sans connexion).
  • Couche Internet (OSI 3) : Gère l'adressage IP et le routage des paquets. C'est le domaine d'IP et ICMP.
  • Couche Accès Réseau (OSI 1, 2) : Fusionne les couches Liaison de Données et Physique de l'OSI. C'est là qu'Ethernet, Wi-Fi et les adresses MAC opèrent.

Différences Clés pour l'Attaquant :

  • OSI : Utile pour isoler la cause d'une vulnérabilité ou d'une défaillance à une couche spécifique. Par exemple, une attaque Wi-Fi vise la couche 2, un déni de service TCP la couche 4, et une injection SQL la couche 7.
  • TCP/IP : Plus pertinent pour les outils et protocoles réellement utilisés.

3. Adressage IP (IPv4 et IPv6)

L'adresse IP est l'identifiant logique d'un appareil sur un réseau.

  • IPv4 : Composée de 4 octets (32 bits), souvent écrite sous forme décimale pointée (ex: 192.168.1.1).
    • Classes d'Adresses : Historiquement, A, B, C, D, E.
    • Adresses Publiques vs. Privées :
      • Privées (non routables sur Internet) :
        • 10.0.0.0 à 10.255.255.255 (Classe A)
        • 172.16.0.0 à 172.31.255.255 (Classe B)
        • 192.168.0.0 à 192.168.255.255 (Classe C)
      • Toutes les autres sont publiques ou réservées.
    • Masque de Sous-réseau (Subnet Mask) : Définit la partie de l'adresse IP qui représente le réseau et la partie qui représente l'hôte. (Ex: 255.255.255.0 pour /24).
    • Notation CIDR (Classless Inter-Domain Routing) : /nombre_de_bits_réseau (Ex: 192.168.1.0/24).
  • IPv6 : Composée de 16 octets (128 bits), écrite en hexadécimal séparé par des deux-points (ex: 2001:0db8:85a3:0000:0000:8a2e:0370:7334).
    • Plus complexe, mais offre un espace d'adressage colossal.
    • Concepts similaires de réseau/hôte mais avec des préfixes.

Pourquoi l'adressage est crucial pour l'attaquant ?
Connaître l'adresse IP d'une cible est la première étape pour l'atteindre. Comprendre les masques de sous-réseau permet de découvrir la plage complète d'adresses d'un réseau et d'identifier toutes les cibles potentielles. Les adresses privées/publiques indiquent si une cible est directement accessible depuis Internet ou se trouve derrière un NAT/routeur.

Mini-Quiz / Exercice Pratique

  1. Question de Théorie : Si une attaque vise à intercepter des communications non chiffrées entre deux applications, à quelle(s) couche(s) du modèle OSI pourrait-elle se situer principalement ? Pourquoi ?
  2. Exercice Pratique (Kali Linux ou Termux) :
    • Ouvrez un terminal.
    • Utilisez la commande ip a (ou ifconfig si ip n'est pas disponible) pour afficher les adresses IP de votre machine.
    • Identifiez l'adresse IPv4 de votre interface réseau principale (généralement eth0 ou wlan0).
    • Quelle est sa notation CIDR ?
    • Déterminez si cette adresse est publique ou privée. Justifiez votre réponse.
    • Utilisez la commande ping 8.8.8.8 (un serveur DNS public de Google). Que remarquez-vous ? Quel protocole est utilisé par ping et à quelle couche TCP/IP opère-t-il ?
